How os.neu works

Three simple steps from this page to a first screen

1

Download the kit

Save neuos-boot-kit.tar.gz. A browser cannot format a stick by itself.

2

Unpack and burn

On Linux list disks, then burn only an empty stick. Never choose the disk that holds /.

3

Power on and speak

Press F12, choose USB, and land on the NeuAvenue logo then the AI prompt.

PC that already has Windows or Linux

The disk is not wiped. Unpack the kit so the next login opens os.neu.

  1. Click Download boot kit.
  2. Unpack and run scripts/install-autostart.sh.
  3. Sign in again — os.neu opens.

USB only, no OS

Burn boot files onto an empty stick, then choose USB in firmware.

  1. Download the boot kit.
  2. On Linux: bash scripts/make-usb.sh --list
  3. Empty stick only: sudo bash scripts/make-usb.sh /dev/sdX --yes
  4. On the target PC press F12 / Esc and choose USB.
