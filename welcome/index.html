The three paths of OS.neu

These links work while the os.neu screen is running on this laptop

PC that already has Windows

The disk is not wiped. The next login opens the OS.neu graphical screen.

  1. Download the boot kit.
  2. Choose PC that already has an OS.
  3. When the bar hits 100%, hardware check → talk screen or DOS console.

No OS, or USB-only

Put OS.neu on a stick, then boot another laptop from USB.

  1. Download the kit or ISO.
  2. Choose USB without an OS.
  3. On the target PC press F8 (ASUS) and choose UEFI USB. If you see grub>, that is not OS.neu yet — follow the USB tutorial.
