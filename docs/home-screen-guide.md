# Home screen guide — os.neu

A short tour of the **first screen**.  
It looks the same when you **Try it** in a browser (`https://os.neuavenue.com`) and when os.neu is **planted** on your PC.

Public seat: [os.neuavenue.com](https://os.neuavenue.com) · Full manual: [manual.en.md](./manual.en.md) · In-app: ☰ → Manual → **Tour of the home screen**

---

## 1. Top bar

1. **Sign in** — optional account (for things like bookmarks when that feature is on).  
2. **Feedback** — send a short note to NeuAvenue.  
3. **OS.neu + version** — product name and version (example: `v1.0.20`).  
4. **Network pill** — `Online` means the internet works. `Offline` means fix Wi‑Fi before cloud AI.  
5. **Language / clock / ×** — change language, see the time, or leave (or close the tab on Try it).

---

## 2. Icon row (circles)

Left → right:

| Icon | Meaning |
|------|---------|
| Plant on this device | Starts install help. On the **website**, this does **not** secretly copy files to your disk. On **Windows Setup** already planted, this icon stays **off**. |
| Burn to USB | Path for a Linux USB stick / Rufus guide. It never aims at the disk that holds `/`. |
| Try now | Look around without installing. |
| NEU VITALITY | Vitality product surface. |
| Download | Get the Linux pack or Windows Setup. |
| Manual | This help. |

On **browser Try it**, you can tap the icons to explore. Trial limits stay as designed.

---

## 3. Headline and prompt

1. Read the short line under the logo.  
2. Type in **Tell me what you want to do**, or use **mic** (right) / **speaker** (left).  
3. Right mic: tap to talk, tap again to send. Left speaker: hear the answer; tap again to replay.

---

## 4. Docs · Sheets · Slides · daf.neu

1. Tap **Docs**, **Sheets**, or **Slides** so the answer can land in that app.  
2. Tap **daf.neu** for the built-in browser and web sources.  
3. Answers show in the **console under the prompt**. Use Link URL / Link file / Find in app.neu to keep sources with the same work.  
4. From **v1.0.27**, Enter on a Docs/Sheets/Slides chip also opens the right-hand **Agent Think** rail (same Cursor-style routine on all three). Walk: [Agent Think guide](./agent-think-docs-sheets-slides-guide.md).
