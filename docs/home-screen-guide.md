# Home screen guide — os.neu

Tutorial base for the first screen. Same face on **Try it** (`https://os.neuavenue.com`) and on a **planted** seat.

Public seat: [os.neuavenue.com](https://os.neuavenue.com) · Full manual: [manual.en.md](./manual.en.md) · In-app: ☰ → Manual → **Tour of the home screen**

---

## 1. Top bar

1. **Sign in** — optional cloud account (bookmarks / history sync when enabled).
2. **Feedback** — send a note to NeuAvenue.
3. **OS.neu + version** — product mark (example: `v1.0.20`).
4. **Network pill** — `Online · 4g` means the session can reach the network. `Offline` means fix Wi‑Fi before cloud AI.
5. **Language / clock / ×** — language menu, local time, leave the seat (or close the tab on Try it).

---

## 2. Icon row (circles)

Left → right:

| Icon | Meaning |
|------|---------|
| Plant on this device | Start install guidance. On the **website**, this does **not** silently copy into your disk. On **Windows Setup** already planted, this icon stays **disabled**. |
| Burn to USB | Linux USB / Rufus guide path. Never targets the disk that holds `/`. |
| Try now | Guest look without installing. |
| NEU VITALITY | Product vitality surface. |
| Download | Get Linux tar or Windows Setup. |
| Manual | This documentation. |

On **browser Try it**, icons stay usable as a trial. Trial limits stay as designed.

---

## 3. Headline and prompt

1. Read the short product line under the logo.
2. Type in **Tell me what you want to do**, or use **mic** (right) / **speaker** (left).
3. Right mic: tap to talk, tap again to send. Left speaker: hear the answer; tap again to replay.

---

## 4. Docs · Sheets · Slides · daf.neu

1. Tap **Docs**, **Sheets**, or **Slides** so the answer lands in that app.
2. Tap **daf.neu** for the built-in browser and web sources.
3. Answers appear in the **console under the prompt**. Use Link URL / Link file / Find in app.neu to keep sources with the same work.

---

## 5. Plant, USB, and body check

1. Open the pill **Plant, USB, and body check**.
2. Three cards: Plant · USB · Try now — **none wipe the internal disk**.
3. Next tutorials:
   - [Try it vs plant (safe)](./try-it-and-plant-guide.md)
   - In-app Manual → **Try it in the browser** · **Plant for real (no disk wipe)**
