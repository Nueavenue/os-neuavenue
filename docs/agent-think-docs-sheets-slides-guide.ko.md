# Agent Think — 문서 · 시트 · 슬라이드 (같은 루틴)

os.neu **v1.0.27**. 공개 좌석: [os.neuavenue.com](https://os.neuavenue.com)

한 줄: 홈에서 **Enter** 하면 Cursor처럼 오른쪽에 **Agent Think**가 열립니다. **가운데 파일이 결과**입니다. 세 앱이 같은 루틴을 씁니다.

영문 짧은 판: [agent-think-docs-sheets-slides-guide.md](./agent-think-docs-sheets-slides-guide.md)

## 빌드

상단이 **OS.neu v1.0.27** 인지 봅니다. v1.0.26이면 Ctrl+Shift+R 또는 이 PC에 심은 os.neu 앱을 엽니다. **AI 고르기**가 켜져 있어야 합니다.

## 세 앱

1. **문서** 칩 → Enter → 오른쪽 Agent Think, 가운데 종이, **Display OK**.  
2. **시트** 칩 → Enter → 같은 Think, 가운데 표. Think에서 **Go** 로 이어서.  
3. **슬라이드** 칩 → Enter → Think가 스튜디오 패널 위.

한 번의 Enter로 세 파일을 한꺼번에 만들지는 않습니다. 앱마다 같은 루틴을 한 번씩, 또는 Think **Go**로 잇습니다. 표/덱이 끝나면 Docs에 쌍둥이 본문이 남습니다.
