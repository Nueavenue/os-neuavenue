# Agent Think — 문서 · 시트 · 슬라이드 (같은 루틴)

os.neu **v1.0.29**. 공개 좌석: [os.neuavenue.com](https://os.neuavenue.com)

한 줄: 홈에서 **Enter** 하면 프롬프트 아래 카드 없이 **바로 Docs**(또는 시트/슬라이드)로 갑니다. Think는 **한 단계씩** 깜빡이고 끝나면 한 줄 요약입니다. 세 앱이 같은 작성창(**▶ 실행**)을 씁니다.

영문 짧은 판: [agent-think-docs-sheets-slides-guide.md](./agent-think-docs-sheets-slides-guide.md)

## 빌드

상단이 **OS.neu v1.0.29** 인지 봅니다. v1.0.28이면 Ctrl+Shift+R 또는 이 PC에 심은 os.neu 앱을 엽니다. **AI 고르기**가 켜져 있어야 합니다.

## 작성창

프롬프트는 예전 한 줄의 약 세 배입니다. 왼쪽은 Agent 글자 + › (모델 바꾸기), 오른쪽은 사용량 · 파일 첨부 · ▶ 실행입니다. Think에는 “읽는 중 / 작성 중 / 수정 중”이 깜빡이고, 검색 스니펫이 붙습니다. 파일을 바꾸면 그 파일의 Think(없으면 빈 기본값)로 바뀝니다.

준비 / 살 것 / 확인 은 **출장·구매 메모**일 때만 씁니다. 제안서·보고서·회의록 등은 각각 다른 절을 씁니다.

## 세 앱

1. **문서** 칩 → Enter → 오른쪽 Agent Think, 가운데 종이, **Display OK**. This work에서도 × 로 지울 수 있습니다.  
2. **시트** 칩 → Enter → 같은 Think + 작성창, 가운데 표.  
3. **슬라이드** 칩 → Enter → Think와 작성창이 스튜디오 도구 위.

한 번의 Enter로 세 파일을 한꺼번에 만들지는 않습니다. 앱마다 같은 루틴을 한 번씩, 또는 작성창 **▶ 실행**으로 잇습니다.
