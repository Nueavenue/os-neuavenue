## Layout (like Cursor)

```text
left files | centre canvas (the file) | Agent Think + composer
```

Composer (all three apps):

- Tall prompt (about 3× the old one-line box)
- Left: Agent glyph + › to switch model
- Right: usage list · file attach · ▶ Run

Live Think: blinking lines such as “파일 읽는 중”, “문단 작성 중”, “문단 수정 중”, plus search snippets in the pane, plus a mint outline on the open file while it writes.

One Agent Think per file. Switch file → that file’s Think, or a blank default.

## Writer shapes (Docs)

The model is **not** locked to 준비 / 살 것 / 확인. That outline is only for a short ops memo (travel / buy list). Other asks pick a matching kind:

| Kind | When you ask for… | Outline |

| Meeting | 회의록 | 일시 · 참석 · 안건 · 논의 · 결정 · 할 일 |

## 1. Docs

1. Home → tap **Docs** (문서) → chip **Docs included**.  
2. Paste a full request → **Enter**.  
3. Watch the **paper** fill. Watch **Agent Think** blink.  
4. Follow-up: type in the composer → **▶ Run**.  
5. Pass = **Display OK · screen N = file N**.

This work: × on a file is available (removes it from the work).

---

## 2. Sheets

1. Back to home → **Sheets** (시트) → Enter a table request.  
2. The **grid** is the canvas. Agent Think + the same composer sit on the right.  
3. Follow-up: composer → **▶ Run**.  
4. A **Docs twin** of the Writer body is also saved.

---

## 3. Slides

1. Home → **Slides** (슬라이드) → Enter a deck request → pick a template.  
2. Agent Think + composer sit **above** the studio tools (element rewrite / QA stay there).  
3. **▶ Run** = another Slides seat run.

---

## 4. How the three apps connect today

One Enter does **not** yet fill all three files (that package is later).

- Run the **same routine** once per app (chip + Enter, or composer **▶ Run**).  
- Move a selection: right-click → **Copy to app.neu**.  
- After Sheets or Slides, open **Docs** for the twin file.

Stop on the Think rail keeps what was already written.
