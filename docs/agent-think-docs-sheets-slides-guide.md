## Layout (like Cursor)

```text
left files | centre canvas (the file) | Agent Think (the routine)
```

Steps on every app: Think → Search → Evidence → Draft → Cite → Revise → Package → Persist → **Display OK** → Go / No-Go.

---

## 1. Docs

1. Home → tap **Docs** (문서) → chip **Docs included**.  
2. Paste a full request (more than 500 characters is the point) → **Enter**.  
3. Watch the **paper** fill. Watch **Agent Think** on the right.  
4. Pass = **Display OK · screen N = file N**. The paper is not the first 500 characters of your prompt.

---

## 2. Sheets

1. Back to home → **Sheets** (시트) → Enter a table request.  
2. The **grid** is the canvas. Agent Think is the new right column.  
3. Type a follow-up in Think and press **Go** — same seat routine, tagged Sheets.  
4. A **Docs twin** of the Writer body is also saved.

---

## 3. Slides

1. Home → **Slides** (슬라이드) → Enter a deck request → pick a template.  
2. Agent Think sits **above** the studio agent panel.  
3. Think **Go** = another Slides seat run. Studio buttons edit the selected slide.

---

## 4. How the three apps connect today

One Enter does **not** yet fill all three files (that package is later).

- Run the **same routine** once per app (chip + Enter, or Think **Go**).  
- Follow-up: Think box → Go.  
- Move a selection: right-click → **Copy to app.neu**.  
- After Sheets or Slides, open **Docs** for the twin file.

Stop on the Think rail keeps what was already written.
