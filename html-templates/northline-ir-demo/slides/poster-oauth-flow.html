🔒 Security Boundary

• No tokens in URL
• Single-use handoff code
• Short TTL (e.g., 60s)
• PKCE + State + Nonce
• Exact redirect URI

Detailed Flow

1User clicks "Sign in with Google" in north.seat
2System browser opens Google OAuth URL
3User authenticates and grants consent
4Google redirects to 127.0.0.1:4178 with authorization code
5north.seat polls for callback result
6osneu://oauth deep link with handoff code (no tokens in URL)
7north.seat exchanges code for tokens (PKCE + state + nonce)
8Backend validates token and creates session
9Session cookie/token is securely delivered to north.seat
10User is logged in and workspace is initialized
11User accesses Browser / Apps / Cloud
12Cloud services validate session and device policy
