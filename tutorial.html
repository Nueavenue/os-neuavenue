os.neu · USB to JeOS

Boot this PC from the stick

After you burn os.neu onto a USB stick, reboot from USB. That does not erase Ubuntu on the internal disk. This session runs from the stick. Unplug it and Ubuntu comes back.

Download boot kit OS.NEU home

1. Confirm the target stick

On Linux, list disks. Never choose the disk that holds /. Never choose a data HDD. 

bash scripts/make-usb.sh --list
bash scripts/make-usb.sh --plan /dev/sdX

If the plan says wipe /dev/sdb and that stick is only an old Ubuntu live image you no longer need, it is the right target. The burn replaces the whole stick. Do not delete files in the file manager first. 

sudo umount /dev/sdX1
sudo bash scripts/make-usb.sh /dev/sdX --yes

2. Reboot this Ubuntu PC from USB

Leave the stick plugged in. Save your work. Restart the computer.

  1. When the maker logo appears, press F12 (or F10 / Esc / Del) several times.
  2. Choose USB / the stick name. Do not choose the internal SSD that runs Ubuntu.
  3. If the Ubuntu desktop opens again, USB was not selected. Restart and pick USB only.

3. What success looks like

There is no folder window and no Firefox. A dark console appears:

neuOS JeOS userspace
Linux kernel + Node runtime. Not motherboard firmware.
Type: hardware | network | memory | install firefox | exit

[neuOS] >

This is the os.neu first console. It is not Windows Explorer and not MS-DOS. The graphical talk screen is a different path (plant os.neu on an existing login).

4. What to type

  1. hardware — this PC’s compute unit
  2. memory — RAM
  3. network — network path
  4. install firefox — shows the matching install command; it does not install in secret
  5. exit — leave the loop

When this PC is online, you can also speak English with the coach (same idea as NeuSpeak). On the graphical console the speaker button next to the prompt plays the reply. On this USB text console, type a sentence in English and the coach answers in text.

5. Return to Ubuntu

  1. Power off, or type exit then power off.
  2. Unplug the USB stick.
  3. Power on. Ubuntu 26.04 on the internal disk should greet you as before.

USB boot does not format the Ubuntu system disk.

6. Next: plant graphical os.neu on this login

After the USB test, boot Ubuntu again (stick unplugged). Then plant the kiosk on this graphical login. The disk is not wiped. 

cd ~/os.neu
npm run boot:install

The next graphical login opens os.neu. Choose the talk screen or the C:\NEUOS> console.
