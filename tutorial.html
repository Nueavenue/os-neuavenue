OS.neu v1.0 · USB to JeOS

Boot this PC from the stick

After you burn OS.neu onto a USB stick, reboot from USB. On an ASUS board that is usually one press of F8 — not a permanent change to the disk order. The internal Ubuntu disk is not erased. Unplug the stick and Ubuntu comes back.

Download boot kit OS.NEU home

1. Confirm the target stick

On Linux, list disks. Never choose the disk that holds /. Never choose a data HDD. 

bash scripts/make-usb.sh --list
bash scripts/make-usb.sh --plan /dev/sdX

If the plan says wipe /dev/sdb and that stick is only an old Ubuntu live image you no longer need, it is the right target. The burn replaces the whole stick. Do not delete files in the file manager first. 

sudo umount /dev/sdX1
sudo bash scripts/make-usb.sh /dev/sdX --yes

2. ASUS: boot from USB once (recommended)

Leave the stick plugged in. Save your work. You do not need to change the permanent boot order. This choice applies to the next start only.

  1. Plug the stick into a rear USB port on the motherboard. Front-panel hubs are less reliable.
  2. Power on.
  3. When the ASUS logo appears, press F8 several times. If nothing happens, try Esc, then F12.
  4. In the Boot Menu, choose UEFI: … USB … (or the stick name). Prefer the line that starts with UEFI:. Do not choose the internal SSD that runs Ubuntu.
  5. Press Enter.

Success is a dark text console, not the graphical talk screen. The prompt looks like [neuOS] >. That is OS.neu JeOS on USB.

If Windows or Ubuntu opens as usual, USB was not selected. Hold the power button to shut down, reseat the stick in a rear port, and repeat from power-on.

3. If the Boot Menu does not open

  1. At power-on press Del (desktop) or F2 (laptop) to enter BIOS.
  2. Use Boot Menu / Boot Override on the right, pick the USB stick, press Enter. That is still a one-time USB start.
  3. If the stick is missing from the list: turn Fast Boot off, turn Secure Boot off (unsigned GRUB can be blocked), then F10 → Yes, restart, and press F8 again.

Do not set Boot Option #1 to USB permanently. Do not open firmware-update or BIOS-flash menus. OS.neu does not live on the motherboard chip.

4. What success looks like

There is no folder window and no Firefox. A dark console appears:

OS.neu v1.0 JeOS
Linux stays hidden. This is not motherboard firmware.
Type: hardware | network | memory | install firefox | exit

[neuOS] >
What you see Meaning
[neuOS] > text prompt USB JeOS is correct. Type hardware or an English sentence.
Usual Ubuntu or Windows USB was not selected. Power off and use F8 again.
payload not found or a GRUB error Wrong image or a weak port. Use a rear motherboard USB port.

The graphical talk screen (mic and WhatsApp-style chat) is a different path: plant OS.neu on an existing login. The USB first screen is this text console.

5. What to type

  1. hardware — this PC’s compute unit
  2. memory — RAM
  3. network — network path
  4. install firefox — shows the matching install command; it does not install in secret
  5. exit — leave the loop

When this PC is online, you can also speak English with the coach (same idea as NeuSpeak). On the graphical console the speaker button next to the prompt plays the reply. On this USB text console, type a sentence in English and the coach answers in text.

6. Return to Ubuntu

  1. Power off, or type exit then power off.
  2. Unplug the USB stick.
  3. Power on. Ubuntu 26.04 on the internal disk should greet you as before.

USB boot does not format the Ubuntu system disk.

7. Next: plant graphical OS.neu on this login

After the USB test, boot Ubuntu again (stick unplugged). Then plant the kiosk on this graphical login. The disk is not wiped. 

cd ~/neuOS
npm run boot:install

The next graphical login opens OS.neu v1.0. Choose the talk screen or the text console.
