USB에 neuOS 부트 파일 만들기

1. 키트 받기

neuos-boot-kit.tar.gz

받은 파일을 홈 폴더에 두고 압축을 풉니다.

tar -xzf neuos-boot-kit.tar.gz

2. USB 고르기 (리눅스)

막대를 꽂은 뒤, / 가 들어 있는 디스크는 절대 고르지 마세요.

bash scripts/make-usb.sh --list
bash scripts/make-usb.sh --plan /dev/sdX

테스트만 (디스크 안 지움):

bash scripts/make-usb.sh --test

빈 막대에 진짜로 굽기:

sudo bash scripts/make-usb.sh /dev/sdX --yes

3. 윈도우 PC에서 키트를 받은 경우

  1. 지금은 굽기 도구가 리눅스용입니다. ISO가 공개되면 Rufus 또는 balenaEtcher로 같은 막대에 구으면 됩니다.
  2. 그동안은 리눅스가 있는 PC에서 키트를 풀어 2번을 하거나, 이미 OS가 있는 PC는 install-autostart.sh 로 로그인 화면에 neuOS를 심습니다.

4. 다른 컴퓨터에서 USB로 켜기

  1. 막대를 꽂고 전원을 켭니다.
  2. 바로 F12 / F10 / Esc / F2 를 눌러 부트 메뉴에서 USB를 고릅니다.
  3. Neuavenue 로고 또는 neuOS 커널 화면이 나오면 성공입니다.
