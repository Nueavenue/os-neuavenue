os.neu · USB walkthrough

Put os.neu on a stick

Same chrome as NeuAvenue: download, unpack, burn, then boot.

Download boot kit Back to os.neu

1. Get the kit

Save the file in your home folder and unpack it.

tar -xzf neuos-boot-kit.tar.gz

2. Pick a USB stick (Linux)

Plug the stick in. Never choose the disk that holds /.

bash scripts/make-usb.sh --list
bash scripts/make-usb.sh --plan /dev/sdX

Test only (does not wipe the disk):

bash scripts/make-usb.sh --test

Real burn onto an empty stick:

sudo bash scripts/make-usb.sh /dev/sdX --yes

3. If you downloaded the kit on Windows

  1. The burn tool is Linux-only for now. When an ISO is published, use Rufus or balenaEtcher on the same stick.
  2. Until then, unpack the kit on a Linux PC and do step 2, or plant os.neu on a PC that already has an OS with install-autostart.sh.

4. Boot another computer from USB

  1. Plug the stick in and power on.
  2. Immediately press F12 / F10 / Esc / F2 and choose USB.
  3. NeuAvenue logo or the os.neu kernel screen means success.
