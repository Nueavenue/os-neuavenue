다운받아 USB로 부팅하기

브라우저는 USB를 몰래 지우지 않습니다. 부트 키트를 받고, 막대를 꽂은 뒤 안내대로 구우면 됩니다. 숙제·사진이 든 막대는 쓰지 마세요.

이미 윈도우·리눅스가 있는 PC

디스크를 안 지웁니다. 키트를 풀어 다음 로그인부터 neuOS 그림 화면을 엽니다.

  1. 아래 부트 키트 받기를 누릅니다.
  2. 압축을 풀고 scripts/install-autostart.sh 를 실행합니다.
  3. 다시 로그인하면 neuOS가 열립니다.

운영체제 없이 USB만으로

빈 막대에 부트 파일을 구워, 다른 컴퓨터 펌웨어에서 USB를 고릅니다.

  1. 부트 키트를 받습니다.
  2. 리눅스에서 bash scripts/make-usb.sh --list 로 막대를 확인합니다.
  3. 빈 막대만 sudo bash scripts/make-usb.sh /dev/sdX --yes
  4. 쓸 PC에서 F12·Esc 등으로 USB 시작을 고릅니다.
