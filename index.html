Download boot kit USB tutorial

Download and boot from USB

A browser never silently erases a drive. Download the kit, plug in a stick, and follow the burn steps. Do not use a stick that holds homework or photos.

PC that already has Windows or Linux

The disk is not wiped. Unpack the kit so the next login opens the neuOS screen.

  1. Click Download boot kit.
  2. Unpack and run scripts/install-autostart.sh.
  3. Sign in again — neuOS opens.

USB only, no OS

Burn boot files onto an empty stick, then choose USB in firmware.

  1. Download the boot kit.
  2. On Linux: bash scripts/make-usb.sh --list
  3. Empty stick only: sudo bash scripts/make-usb.sh /dev/sdX --yes
  4. On the target PC press F12 / Esc and choose USB.
