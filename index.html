You do not need Windows or Linux literacy. Put neuOS on a USB stick, power on, and land on an AI first screen.

Download and boot from USB

A browser never silently erases a USB drive. Download the boot kit, plug in a stick, and follow the burn steps. Do not use a stick that holds homework or photos.

PC that already has Windows or Linux

The disk is not wiped. Unpack the kit so the next login opens the neuOS graphical screen.

  1. Click Download boot kit below.
  2. Unpack and run scripts/install-autostart.sh.
  3. Sign in again — neuOS opens.

USB only, no OS

Burn boot files onto an empty stick, then choose USB in the other PC’s firmware.

  1. Download the boot kit.
  2. On Linux, list sticks with bash scripts/make-usb.sh --list.
  3. Empty stick only: sudo bash scripts/make-usb.sh /dev/sdX --yes
  4. On the target PC press F12 / Esc and choose USB.
